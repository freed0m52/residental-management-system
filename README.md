# Система управления жилым комплексом

Консольное приложение для управления многоквартирным жилым комплексом.

## Возможности

- Регистрация жителей
- Просмотр и поиск жителей
- Создание заявок на обслуживание
- Просмотр и фильтрация заявок
- Статистика по заявкам
- Сохранение данных в JSON-файлах

## Структура проекта

- `main.py` - точка входа, меню приложения
- `residents.py` - функции работы с жителями
- `requests.py` - функции работы с заявками
- `storage.py` - сохранение и загрузка JSON
- `utils.py` - вспомогательные функции
- `data/` - JSON-файлы с данными
- `tests/` - автоматизированные тесты

## Требования

- Python 3.8+
- pytest (для тестов)
- flake8 (для проверки качества кода)
