# Система управления жилым комплексом

## Назначение
Приложение предназначено для автоматизации управления многоквартирным жилым комплексом. Позволяет регистрировать жильцов, управлять помещениями, обрабатывать заявки и предоставлять услуги.

## Целевая аудитория
- Управляющая компания (администраторы)
- Жильцы комплекса
- Сотрудники обслуживающих служб

## Предметная область
Жилой комплекс включает в себя жилые и нежилые помещения, в которых проживают или работают жильцы. Жильцы могут подавать заявки на обслуживание (ремонт, уборка, сантехника и т.д.) и пользоваться дополнительными услугами (парковка, охрана, клининг).

## Основные сущности
- **Житель** - ФИО, номер квартиры, контактный телефон, статус (собственник/арендатор)
- **Помещение** - номер, тип (жилое/коммерческое), площадь, статус (свободно/занято)
- **Заявка** - дата создания, тип (ремонт, уборка, сантехника), статус (новая/в работе/выполнена), описание
- **Услуга** - название, стоимость, описание, периодичность

## Основные функции
1. **Регистрация нового жителя** - добавление жителя в систему
2. **Подача заявки на обслуживание** - создание новой заявки от жильца
3. **Просмотр статуса заявки** - проверка текущего статуса по номеру заявки
4. **Поиск помещения по номеру** - получение информации о статусе помещения

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django с удобным интерфейсом
- подключение базы данных (PostgreSQL) для хранения информации
- реализация системы авторизации с разделением ролей (админ/жилец)
- разработка REST API для мобильного приложения
- контейнеризация приложения в Docker
- настройка CI/CD для автоматического деплоя
